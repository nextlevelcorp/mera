# Founder skills: marketing, pricing, launch (business questions only)

**Use only when the owner asks a business, marketing, pricing or launch question.** Never load it for
game design, code, data or art work. The installed skills do the work; this file says which to use.

| Question from the owner | Skill |
| --- | --- |
| Would this work, pressure-test the idea | founder-board |
| Who are the competitors, where is the gap | founder-competitors |
| Would people buy it, simulate buyers | founder-consumer |
| What should it cost | founder-pricing (after founder-consumer) |
| Make the offer better | founder-offer |
| Unit economics, break-even, cash needed | founder-cfo |
| Marketing plan, channels, campaign | founder-marketing |
| Name, voice, look of the brand | founder-brand |
| How to run it day to day | founder-ops |
| Launch plan, cheap real-world test | founder-launch |
| Put it all in one plan | founder-plan |

## Rules for Mera

- Facts about the market come with links; simulated buyer panels are labelled as simulations, never
  as evidence of demand (see `docs/research.md`).
- Decisions already taken stand unless the owner reopens them: MVP free, no ads, no energy timers, no
  pay-to-win; later a one-time paid release; anonymous counters only (`docs/prd.md`).
- Anything that costs money, collects player data or changes scope needs the owner's go-ahead.
