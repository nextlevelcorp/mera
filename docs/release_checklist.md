# Release checklist

Nothing ships to a store until all four gates are closed and recorded here (spec 6.6).

- [ ] 1. Full test pass and audit: playthrough on target devices, performance check, save migration check, localisation check in en, tr, es.
- [ ] 2. Security audit: dependencies, CI secrets, exported build contents, network calls.
- [ ] 3. Store and legal: developer accounts, age rating, privacy policy, data-safety forms, attribution and licence notices.
- [ ] 4. Owner sign-off.
